# 攻击链溯源分析指南

## 溯源目标
在综合防御赛中，溯源报告准确性是重要评分项。需还原：初始访问 → 漏洞利用 → 权限提升 → 权限维持 → 横向移动 → 影响，并定位攻击源与时间线。

## 日志与时间线重建
- Linux：/var/log/auth.log、/var/log/secure（SSH 登录）、auditd、history、/var/log/nginx/access.log
- Windows：Event Log（4625 登录失败、4688 进程创建）、Sysmon
- 网络：防火墙/Suricata/Zeek 连接日志、pcap
- 应用：Web 访问日志中的攻击 payload、报错栈

## 后门排查清单
- 文件：Web 目录新增/篡改的脚本、/tmp 下可执行、最近 mtime 突变文件（find / -mmin -30）
- 进程：异常进程、父进程异常、命令行含 base64/iex/curl|sh
- 启动项：crontab -l、/etc/rc.local、systemd、/etc/init.d、at 任务
- 账户：/etc/passwd 异常、~/.ssh/authorized_keys、sudoers
- 网络：netstat -antp / ss 异常外连、可疑监听端口
- 库劫持：/etc/ld.so.preload、LD_PRELOAD、恶意 .so、计划任务调用

## 攻击链还原方法
1. 以告警时间为中心，向前找初始访问（扫描/爆破/钓鱼）
2. 向后找权限提升与维持（新增账户、后门文件、服务）
3. 横向：同源 IP 的其他目标、内网探测痕迹
4. 关联 IOC：同一 payload、同一 User-Agent、同一外连 IP

## 工具链
Volatility（内存取证）、Autoruns/Process Hacker（Windows）、Wireshark、YARA（恶意样本）、grep/awk（日志）、auditd。

## 溯源报告要素
攻击源 IP、攻击时间线、利用漏洞/路径、受影响资产、后门/残留、处置与加固措施、证据截图。务必与 WAF 拦截日志、文件监控事件互为印证。
