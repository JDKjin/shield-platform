# 流量抓包与网络取证手册

> 网络取证是还原攻击链的关键一环：抓包定位异常外连、分析协议载荷、从流量还原攻击手法。比赛与应急中用于判断「谁在打我、打了什么、往哪回连」。

## 一、抓包工具与时机

```bash
# tcpdump 抓包（先确认网卡）
ip a | grep -E '^[0-9]+:' 
tcpdump -i eth0 -nn -s0 -w /root/evidence/capture.pcap        # 全量抓包
tcpdump -i any -nn -s0 'port 8080' -w /root/evidence/web.pcap # 只抓业务口
tcpdump -i any -nn -s0 'host 攻击IP' -w /root/evidence/atk.pcap # 抓攻击来源
# 不落盘实时看（应急时快速判断）
tcpdump -i any -nn -c 50
```

> 抓包要点：第一时间抓（攻击进行时最有价值）、落盘到取证目录、记录抓包起止时间。

## 二、用 tshark 分析 pcap

```bash
# 1. 顶层协议分布（判断是不是扫描/攻击流量）
tshark -r capture.pcap -q -z io,phs
# 2. TCP 会话 Top（找到流量最大的会话）
tshark -r capture.pcap -q -z conv,tcp | head -20
# 3. HTTP 请求列表（还原 Web 攻击路径）
tshark -r web.pcap -Y 'http.request' -T fields -e ip.src -e http.request.method -e http.request.uri | head -50
# 4. 可疑字符串（WebShell 关键字/明文口令）
tshark -r capture.pcap -Y 'http' -T fields -e http.host -e http.request.full_uri | grep -iE 'eval|union|select|upload|\.php'
# 5. DNS 查询（DNS 隧道/外连痕迹）
tshark -r capture.pcap -Y 'dns.qr==1' -T fields -e dns.qry.name | sort -u | head -30
```

## 三、常见取证分析点

| 分析点 | 命令/方法 | 判断 |
|--------|----------|------|
| 扫描特征 | `conv,tcp` + 短会话数 | 大量短连接/全端口 = 扫描 |
| 爆破特征 | 同源 IP 大量 401/失败 + 重连 | 爆破来源 |
| 后门回连 | `tcpdump 'tcp[tcpflags] & tcp-syn != 0'` 找非常规端口出站 | 外连非常规端口 |
| 上传特征 | `http.request.method == POST` + 响应 200 | 找 WebShell 上传 |
| 隧道特征 | 大流量 UDP/DNS 高频率 | DNS/ICMP 隧道 |
| 工控攻击 | Modbus 502 功能码 05/06/15/16 写操作 | 工控写线圈/寄存器 |

## 四、Windows 抓包

```powershell
# netsh trace（不装 Wireshark 时）
netsh trace start capture=yes file=C:\evidence\net.etl
netsh trace stop
# 用 Message Analyzer/Wireshark 打开分析
```

## 五、包内取证要点

1. **还原攻击载荷**：从 pcap 直接导出 HTTP body，`strings` 提取可疑文件/命令。
2. **对应日志时间线**：抓包时间轴与 access.log、secure 日志比对，锁定攻击窗口。
3. **写报告**：把关键包（SYN 扫描段、POST 上传段、回连段）时间戳与特征写进溯源报告。
4. **保留证据**：pcap 文件完整性 `sha256sum`，勿在处置时覆盖原始抓包。
