# 恶意样本初步分析手册

> 靶机上发现可疑文件（WebShell、挖矿程序、勒索样本、注入脚本）时，先做初步静态分析定性，再决定处置。目标：判断「是什么、做什么、连哪里、怎么清理」，为报告提供证据。

## 一、静态分析（不运行）

```bash
# 1. 文件类型与元信息
file 样本文件
ls -la 样本文件; stat 样本文件          # 大小、时间戳
md5sum 样本文件; sha256sum 样本文件     # 哈希（用于查 VT/威胁情报）

# 2. 可执行文件：查看 ELF 信息与字符串
strings -a 样本文件 | grep -iE 'http|tcp|socket|/dev/tcp|wget|curl|powershell|/bin/bash' | head -30
readelf -h 样本文件 | head -20          # ELF 头
readelf -d 样本文件 | grep -i NEEDED    # 动态链接依赖

# 3. 脚本类：直接看源码
head -50 样本.sh / 样本.php / 样本.py
grep -iE 'download|upload|exec|system|curl|wget|connect|socket' 样本文件

# 4. 网页木马：分析混淆
grep -oE 'eval\([^)]*\)' 样本.php | head
# 常见混淆：base64 + gzinflate 嵌套，逐层解码
php -r "echo gzinflate(base64_decode('...'));"
```

## 二、动态行为确认（受控环境，慎用）

```bash
# 在隔离环境（无外网）用 strace 观察系统调用
strace -f -e trace=network,file,process ./样本文件 2>&1 | head -100
# 监控文件变化
find / -newer 样本文件 -type f -mmin -5 -ls 2>/dev/null
# 监控网络行为
tcpdump -i any -nn -s0 -w /root/evidence/run.pcap &
./样本文件
```

> 动态执行只在隔离靶机/虚拟机中进行，先断外网（`iptables -P OUTPUT DROP`）再跑。

## 三、挖矿样本判定要点

```bash
# 特征：高 CPU、矿池 IP/端口、随机进程名、自毁/守护
grep -iE 'stratum|pool|xmrig|minerd|nicehash|monero' 样本文件
# 矿池常用端口：3333/4444/5555/14444（配合封禁）
```

## 四、勒索/蠕虫样本判定

- 字符串含加密扩展名、赎金说明、批量遍历 `find / -name`。
- 通常需要网络回连或横向（SMB 445），立即隔离断网。

## 五、样本处置与报告

1. **不删原件**：可疑样本一律先 `cp` 到取证目录并 `chmod 000`，保留原始 hash。
2. **记录 IOC**：文件 hash、外连 IP/域名、文件名、落盘时间、父进程，全部写入报告。
3. **溯源父进程**：`ls -l /proc/<启动PID>/exe` + 历史命令 + 计划任务，锁定投放渠道。
4. **清理残留**：按「持久化后门排查」清启动项/计划任务/守护进程，再重启承载服务。
