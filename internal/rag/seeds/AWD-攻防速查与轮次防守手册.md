# AWD 攻防速查与轮次防守手册

> 面向 AWD/综合防御赛的实战速查。赛事为轮次制：攻击方定期攻击，防守方每轮要「补洞 → 防打 → 应急 → 抢题」。本手册把一轮防守的完整动作压缩成可照做的清单。

## 一、开局黄金 5 分钟（前 30 分钟）

1. **备份**：`tar czf /tmp/backup.tar.gz /var/www/html /usr/local/tomcat/webapps`，`mysqldump -u root -p 全部库 > /root/backup.sql`。
2. **改口令**：MySQL root、Redis、phpMyAdmin、Web 后台、SSH 全部换强口令（参考「弱口令与账号安全排查手册」）。
3. **清预置后门**：`find /var/www -type f -mmin -180` 找开赛前被放的马，`grep -rlE 'eval\(|base64_decode|\$_POST' /var/www/`。
4. **起 WAF**：对每台 Web 靶机部署软 WAF，curl 冒烟业务 200、注入 payload 被拦。
5. **系统加固**：SSH 加固、防火墙启用、禁危险 PHP 函数、收紧 Web 目录权限（参考「SSH 手册」「Linux 加固清单」）。
6. **建基线**：留存检测空态截图与告警基线，后续增量异常一眼可辨。

## 二、每轮开始前 60 秒检查（轮次节奏）

- `ss -tlnp` 有无新监听端口、`ps -ef` 有无新进程（对照上轮快照）。
- `crontab -l`、`cat /etc/cron.d/*` 有无新增计划任务。
- `find /var/www -type f -mmin -N` 有无新增文件（N=距上轮分钟数）。
- 面板告警/WAF 拦截有无异常 IP，异常即 `ban_ip`。

## 三、被攻破后的 15 分钟处置（照做）

1. **0-3 分钟断入口**：封攻击源 IP（`iptables -I INPUT -s <IP> -j DROP`），Web 入口则 `systemctl restart tomcat nginx php-fpm` 踢掉已建立连接。
2. **4-6 分钟清驻留**：`ps -ef | grep -Ei 'nc|bash -i|xmrig'` 命中即 `kill -9`，清可疑 crontab。
3. **7-10 分钟溯源**：`grep Accepted /var/log/secure`、`find /var/www -mmin -30`，`cp` 证据到 /root/evidence 存档。
4. **11-13 分钟加固**：一键加固（锁空口令、清计划任务、收紧目录权限），`passwd` 改本地口令。
5. **14-15 分钟抢题**：题目开放立即作答；Writeup 题同步按模板开始写证据链。

## 四、flag 衰减计分应对

```
P = S × [ L / (N + L − 1) ]
```

- 初级题（55 分）人人会做，比手速，开题 30 秒内就要把 flag 提交出去。
- 被攻破后平台会开放对应题作答权，等于对方替你开了题，立刻去提交，别等。
- 攻击失败轮次结束后自动开放作答且不扣分，是白拿分的窗口，保持监测到"这轮没被打"就马上去做该题。
- 高级题（90 分）解出人数少，衰减小，优先保证防守到位再慢慢答。

## 五、防线自检清单（防住三类攻击）

| 攻击模式 | 高频手法 | 防线 |
|---------|---------|------|
| 红队渗透 | WebShell、命令注入、反序列化 | WAF 规则、危险函数禁用、Web 目录只读 |
| 自动化脚本 | 弱口令批量爆破、批量传马 | 改默认口令、上传目录禁执行、SSH 限速封禁 |
| 历史流量回放 | 已知漏洞固定载荷（upload/admin/api 路径） | WAF 规则覆盖已知特征、补对应漏洞、封回放源 |

## 六、收尾（比赛结束前）

1. 导出告警时间线、拦截日志、加固前后截图、指令回执。
2. 按「应急监测 → 溯源分析 → 安全加固」三段整理整体解题报告。
3. 时间线、IOC、证据三者互相印证，确保每个被攻破的题都有完整处置记录。
