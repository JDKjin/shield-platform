# AWD 攻防对抗实战要点

## 一、AWD 比赛规则理解
- 防守核心是"保住权限"：被拿下权限才扣题分+开放作答，攻击失败则不扣分
- 三种攻击模式同时进行：红队渗透、自动化脚本、历史流量回放
- flag 题计分公式（标准）：P = S * L / (N + L - 1)，越早提交分值越高

## 二、开局黄金 5 分钟
1. 先备份 Web 目录与数据库：`tar czf /tmp/backup.tar.gz /var/www/html`
2. 修改弱口令：MySQL root、phpMyAdmin、Web 后台默认密码
3. 删除明显后门文件（优先删除会被别人打点利用的）
4. 部署软 WAF（.user.ini + auto_prepend_file）
5. 检查系统账号与 SSH 配置
6. 备份后修改 SSH 端口、禁用 root 密码登录

## 三、防守优先级
1. **保住权限 > 拿 flag**：权限一旦丢失，需要重新打进去，风险极高
2. 先内网加固（SSH、防火墙、账号），再处理 Web 层
3. 被攻破后快速定位入侵点，清理后门同时更新防护
4. 对流量回放攻击：重点防已知漏洞的利用载荷

## 四、常见攻击路径与防御
| 攻击路径 | 防御措施 |
|---------|---------|
| 弱口令爆破 | 修改默认密码、限速 |
| SQL 注入 | 软 WAF 拦截、参数过滤 |
| 上传马 | 上传目录禁执行、WAF 拦截 |
| 命令注入 | WAF 拦截 shell 函数 |
| 反序列化 | 更新组件、WAF 特征拦截 |
| SSRF | 禁用危险函数、出网限制 |

## 五、流量回放防御
- 历史流量中可能包含已知攻击载荷
- 用软 WAF 的规则库覆盖已知漏洞特征
- 对常见路径（upload、admin、api）重点防护

## 六、应急响应
- 被攻破后：断网隔离 -> 定位后门 -> 清理 -> 补防 -> 修改密码
- 保留入侵痕迹用于溯源报告
- 快速重启服务验证 Web 可用性

## 七、能源行业靶场特点
- 常见 Web 应用：SCADA 管理后台、能源监控系统、工业控制平台
- 重点关注：工控系统弱口令、Web 管理接口暴露、历史漏洞组件
- 数据价值高，flag 常藏在工控数据库或管理后台中
