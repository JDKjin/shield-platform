# 加固清单深化：验证与回滚手册

> 手册目标：把 Linux/Windows 关键加固项做成"目标 → 加固命令 → 验证命令 → 回滚命令"四栏表格，确保**加固可执行、可验证、可回滚**。生产建议先备份再执行，每项改动记录到加固台账。

## 核心原则

- **先备份**：改配置前 `cp file file.bak`（Linux）或导出注册表（Windows）。
- **验证优先**：每条加固必须有对应的验证命令，确认"确实生效"而非"看起来生效"。
- **回滚预案**：加固导致服务不可用时要能快速恢复（AWD 中加固失误比攻击更致命）。
- **只读先行**：先观察现状（`ss -antp`、`systemctl list-units`），再改，防止误杀业务。

## SSH 加固

| 目标 | 加固命令 | 验证命令 | 回滚命令 |
|------|---------|---------|---------|
| 禁用 root 直接登录 | `sed -i 's/#PermitRootLogin yes/PermitRootLogin no/' /etc/ssh/sshd_config` | `sshd -T \| grep PermitRootLogin` | 改回 `PermitRootLogin yes` |
| 禁止口令登录（仅密钥） | `sed -i 's/#PasswordAuthentication yes/PasswordAuthentication no/' /etc/ssh/sshd_config` | `sshd -T \| grep PasswordAuthentication` | 改回 yes |
| 仅允许白名单用户 | `echo "AllowUsers webadmin" >> /etc/ssh/sshd_config` | `sshd -T \| grep AllowUsers` | `sed -i '/AllowUsers/d'` |
| 限制 SSH 端口 | `sed -i 's/#Port 22/Port 2222/' /etc/ssh/sshd_config` | `ss -antp \| grep 2222` | 改回 22 并同步防火墙 |
| 空闲超时断开 | `echo "ClientAliveInterval 300" >> /etc/ssh/sshd_config` | `sshd -T \| grep ClientAliveInterval` | 删除该行 |
| 重启服务 | `systemctl reload sshd` | `systemctl status sshd` | `systemctl restart sshd` |

- **注意事项**：改 `sshd_config` 前**务必先保留一个活动会话**，改完验证能登录再退出；改了端口要同步防火墙放行规则，否则自己把自己锁死（回滚需控制台）。

## 防火墙加固（firewalld / iptables）

| 目标 | 加固命令 | 验证命令 | 回滚命令 |
|------|---------|---------|---------|
| 仅放行业务端口 | `firewall-cmd --permanent --remove-service=http --remove-service=ssh --add-port=80/tcp --add-port=443/tcp && firewall-cmd --reload` | `firewall-cmd --list-all` | `firewall-cmd --add-service=http --permanent` |
| 封禁指定 IP | `firewall-cmd --permanent --add-rich-rule='rule family=ipv4 source address=203.0.113.9 reject' && firewall-cmd --reload` | `firewall-cmd --query-rich-rule='rule family=ipv4 source address=203.0.113.9 reject'` | `firewall-cmd --permanent --remove-rich-rule='...'` |
| 阻断出站非业务端口 | `firewall-cmd --permanent --direct --add-rule ipv4 filter OUTPUT 0 -m multiport --dports 4444,5555,7000 -j DROP` | `firewall-cmd --direct --get-all-rules` | 删除对应 rule |
| 备份规则 | `firewall-cmd --permanent --list-all > /root/fw.bak.txt` | `cat /root/fw.bak.txt` | 直接 reload 恢复默认 |
| 完整备份 | `cp -r /etc/firewalld /root/fw_bak_$(date +%F)` | `ls /root/fw_bak_*` | `cp -r /root/fw_bak_*/* /etc/firewalld/ && systemctl restart firewalld` |

- **注意事项**：先做"封禁"前务必确认业务端口清单，测试连接后提交（`--permanent` + `--reload` 顺序不可反）。

## 账户策略加固

| 目标 | 加固命令 | 验证命令 | 回滚命令 |
|------|---------|---------|---------|
| 锁定空口令账户 | `awk -F: '($2==""){print $1}' /etc/shadow` 后 `passwd -l <user>` | `passwd -S <user>` | `passwd -u <user>` |
| 禁止 uid=0 非 root 用户 | `awk -F: '($3==0){print $1":"$3}' /etc/passwd` | 复查列表为空 | 改回原 uid |
| 删除未知用户 | `userdel -r <user>` | `grep <user> /etc/passwd` | 重新 `useradd` + 恢复 home |
| 锁定不必要账户 | `usermod -L <user>` | `passwd -S <user>` | `usermod -U <user>` |
| 删除无主文件风险 | `find / -nouser -o -nogroup 2>/dev/null` | 列表输出 | chown 修正 |

- **注意事项**：禁用账户前先确认该账户无业务进程依赖；`userdel -r` 会删 home，务必先备份。

## 口令策略加固

### Linux（PAM）
| 目标 | 加固命令 | 验证命令 | 回滚命令 |
|------|---------|---------|---------|
| 密码复杂度 | `echo "password requisite pam_pwquality.so retry=3 minlen=12 dcredit=-1 ucredit=-1 ocredit=-1" >> /etc/pam.d/system-auth` | 试设弱密码确认被拒 | 删除该行 |
| 密码有效期 90 天 | `sed -i 's/PASS_MAX_DAYS.*/PASS_MAX_DAYS  90/' /etc/login.defs` | `chage -l <user>` | 改回 99999 |
| 密码最小长度 | `sed -i 's/PASS_MIN_LEN.*/PASS_MIN_LEN  12/' /etc/login.defs` | `chage -l <user>` | 改回 5 |
| 失败锁定 | `echo "auth required pam_tally2.so deny=5 unlock_time=600" >> /etc/pam.d/sshd` | 错 5 次后确认锁定 | 删除该行 |

### Windows（net 命令）
```powershell
# 密码策略（组策略对应项：安全设置->账户策略）
net accounts /minpwlen:12 /maxpwage:90 /lockoutthreshold:5 /lockoutduration:30
# 验证
net accounts
# 回滚
net accounts /minpwlen:0 /maxpwage:0 /lockoutthreshold:0
```

## Web 目录权限加固

| 目标 | 加固命令 | 验证命令 | 回滚命令 |
|------|---------|---------|---------|
| Web 根只读 | `chmod -R 555 /var/www/html` | `ls -ld /var/www/html` / 访问测试 | `chmod -R 755` |
| 写目录单独授权 | `chmod 755 /var/www/html/uploads && chown www-data:www-data /var/www/html/uploads` | `stat /var/www/html/uploads` | 改回 777（慎用） |
| 禁止执行上传目录 | Nginx：`location ~* ^/uploads/.*\.php$ { deny all; }` | `curl -I http://ip/uploads/a.php` 应 403 | 删除 location 块 |
| 禁止源码/备份泄露 | `find /var/www/html \( -name "*.bak" -o -name "*.zip" -o -name "*.tar" \) -delete` | `find /var/www/html -name "*.bak"` | 从备份恢复 |
| PHP 禁用危险函数 | `sed -i 's/disable_functions =/disable_functions = system,exec,passthru,shell_exec,popen,proc_open/' /etc/php.ini` | `php -r 'echo ini_get("disable_functions");'` | 清空该行 |

- **注意事项**：`chmod 555` 会导致上传类功能失败（上传目录需写权限），先小流量验证再全面执行。

## 服务最小化加固

| 目标 | 加固命令 | 验证命令 | 回滚命令 |
|------|---------|---------|---------|
| 停用无用服务 | `systemctl stop <svc> && systemctl disable <svc>` | `systemctl is-enabled <svc>` | `systemctl enable <svc>` |
| 列出开机服务 | `systemctl list-unit-files --type=service --state=enabled` | 人工核对清单 | — |
| 查看监听端口对应服务 | `ss -tlnp` | 核对业务端口 | — |
| 关闭 CUPS（打印服务常被利用） | `systemctl stop cups; systemctl disable cups` | `systemctl is-active cups` | `systemctl enable cups` |
| 关闭 rpcbind/nfs | `systemctl disable rpcbind nfs-server` | `ss -antp \| grep -E "111|2049"` | `systemctl enable` |

- **注意事项**：禁用前用 `ss -tlnp` 确认无业务依赖；比赛场景"停服务"类加固需与业务方确认（AWD 中停错服务 = 丢分）。

## 日志审计加固

| 目标 | 加固命令 | 验证命令 | 回滚命令 |
|------|---------|---------|---------|
| 日志永久保留 | `sed -i 's/^#rotate.*/rotate 7/' /etc/logrotate.conf && logrotate -f /etc/logrotate.conf` | `cat /etc/logrotate.conf \| grep rotate` | 改回默认 |
| 开启 auditd | `yum install -y audit && systemctl enable --now auditd` | `auditctl -l` / `systemctl status auditd` | `systemctl stop auditd` |
| 审计 Web 目录 | `auditctl -w /var/www/html -p wa -k webdir` | `auditctl -l \| grep webdir` | `auditctl -W /var/www/html` |
| 审计关键命令 | `auditctl -a always,exit -F arch=b64 -S execve -k exec` | `ausearch -k exec \| tail` | `auditctl -d always,exit ...` |
| 同步系统时间（时间线准确） | `timedatectl set-ntp true` | `timedatectl status` | `timedatectl set-ntp false` |
| 日志远程集中（可选） | rsyslog 配 `*.* @logserver:514` | `logger "test"` 后在服务端验证 | 删除该行 |

- **注意事项**：auditd 规则过多会拖慢系统；先加核心目录即可；`ausearch -ts` 可查指定时间窗事件。

## 内核参数加固（sysctl 网络加固）

| 目标 | 加固命令 | 验证命令 | 回滚命令 |
|------|---------|---------|---------|
| 禁止 ICMP 重定向 | `sysctl -w net.ipv4.conf.all.accept_redirects=0` | `sysctl net.ipv4.conf.all.accept_redirects` | 置回 1 |
| 禁止转发（非路由机） | `sysctl -w net.ipv4.ip_forward=0` | `sysctl net.ipv4.ip_forward` | 置回 1 |
| 开启 SYN cookies | `sysctl -w net.ipv4.tcp_syncookies=1` | `sysctl net.ipv4.tcp_syncookies` | 置回 0 |
| 限制并发 SYN | `sysctl -w net.ipv4.tcp_max_syn_backlog=1024` | `sysctl net.ipv4.tcp_max_syn_backlog` | 改回 4096 |
| 关闭源路由 | `sysctl -w net.ipv4.conf.all.accept_source_route=0` | `sysctl net.ipv4.conf.all.accept_source_route` | 置回 1 |
| 禁止 ptrace（防注入） | `sysctl -w kernel.yama.ptrace_scope=1` | `sysctl kernel.yama.ptrace_scope` | 置回 0 |
| 随机内核地址空间（ASLR） | `sysctl -w kernel.randomize_va_space=2` | `sysctl kernel.randomize_va_space` | 置回 0 |
| 持久化 | `echo "net.ipv4.tcp_syncookies=1" >> /etc/sysctl.d/99-hardening.conf && sysctl -p` | `sysctl net.ipv4.tcp_syncookies` | 删除该文件对应行 |

- **注意事项**：`ip_forward=0` 会中断 Docker 容器跨主机/端口映射（Docker 依赖转发），**容器环境不要关**；每个参数修改后先验证业务连通再持久化。

## Windows 关键加固速查（验证/回滚要点）

| 目标 | 加固命令 | 验证命令 | 回滚命令 |
|------|---------|---------|---------|
| 关闭 445/SMBv1 | `Disable-WindowsOptionalFeature -Online -FeatureName SMB1Protocol -NoRestart` | `Get-SmbServerConfiguration \| Select EnableSMB1Protocol` | `Enable-WindowsOptionalFeature` |
| 开启防火墙 | `Set-NetFirewallProfile -Profile Domain,Private,Public -Enabled True` | `Get-NetFirewallProfile` | `-Enabled False` |
| 关闭远程注册表 | `Set-Service RemoteRegistry -StartupType Disabled; Stop-Service RemoteRegistry` | `Get-Service RemoteRegistry` | 设回 Manual + Start |
| 关闭 Guest | `Disable-LocalUser -Name Guest` | `Get-LocalUser Guest` | `Enable-LocalUser` |
| 审核登录 | `auditpol /set /subcategory:"登录/注销" /success:enable /failure:enable` | `auditpol /get /category:"登录/注销"` | `auditpol /clear` |
| 3389 限制来源 | 防火墙规则仅允许指定 IP | `Get-NetFirewallRule -DisplayName "*RDP*"` | 删除规则 |

## 加固总台账 Checklist

- [ ] 每项加固执行前：记录原值（配置/注册表/基线输出）
- [ ] 执行后立即跑验证命令，结果存入 `/root/hardening_verify.log`
- [ ] 关键服务改动前确认活动会话/控制台可用
- [ ] 每项改动记录：目标、命令、验证结果、时间、执行人（赛后可溯源）
- [ ] 全部完成后做一次业务连通性测试（HTTP/SSH/数据库）
- [ ] 保留完整回滚方案（备份文件位置、原始配置内容）
