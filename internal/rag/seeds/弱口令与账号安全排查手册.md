# 弱口令与账号安全排查手册

> 弱口令/默认口令是能源防御赛最高频打点方式（Web 后台、SSH、MySQL、Redis、工控 HMI）。排查三件事：找弱口令、找后门账号、锁口令策略。

## 一、系统账号排查

```bash
# 1. UID 0 账号（隐藏 root，必须只有一个 root）
awk -F: '$3==0{print $1":"$7}' /etc/passwd

# 2. 空口令账号（可免密登录）
awk -F: '($2==""){print $1}' /etc/shadow

# 3. 可登录 shell 的账号清单
grep -E 'bash|sh$' /etc/passwd

# 4. 最近创建的用户（对比开赛快照）
ls -ld /home/* 
awk -F: '$3>=1000 && $3<65534{print $1,$3}' /etc/passwd

# 5. 影子文件口令类型分析（$6$=sha512 可离线爆破）
awk -F: '$2!="*" && $2!="!!" && $2!=""{print $1":"$2}' /etc/shadow
```

## 二、Web / 中间件 / 数据库默认口令核查

| 组件 | 默认口令示例 | 核查点 |
|------|------------|--------|
| phpMyAdmin | root/root、root/123456 | `mysql -uroot -p123456` |
| MySQL | root 空口令、root/root | `mysql -uroot` |
| Redis | 空口令 | `redis-cli ping` |
| Tomcat 管理台 | tomcat/tomcat、admin/admin | `/manager/html`、`conf/tomcat-users.xml` |
| SSH | root/123456、root/password | `grep 'Failed' /var/log/secure` |
| 工控 HMI/SCADA | admin/admin、admin/123456 | Web 后台登录页（能源场景重点） |

## 三、口令策略加固

```bash
# Linux 口令策略（/etc/login.defs）
PASS_MAX_DAYS 90
PASS_MIN_LEN 12
# 立即锁定危险账号
passwd -l <后门/不需要的账号>
# 强制用户下次改口令
chage -d 0 <账号>
# 禁用 root 远程登录（配合 SSH 手册）
echo 'PermitRootLogin no' >> /etc/ssh/sshd_config && systemctl restart sshd
```

## 四、Windows 账号排查

```powershell
# 管理员组名单（对照基线）
net localgroup Administrators
# 空口令/永不失效账户
Get-LocalUser | Where-Object { $_.PasswordRequired -eq $false }
# 开启账户锁定防爆破
net accounts /lockoutthreshold:5 /lockoutduration:15
# 禁用不必要账户
net user <账户> /active:no
```

## 五、密码字典化自测（合法环境自查）

```bash
# 用 hydra 对本机服务自测（仅限自己靶机，确认弱口令存在）
hydra -l root -P 常用弱口令.txt ssh://127.0.0.1
hydra -l admin -P 常用弱口令.txt http-post-form "/login.php:user=^USER^&pass=^PASS^:F=error"
# MySQL 自测
hydra -l root -P 常用弱口令.txt mysql://127.0.0.1
```

## 六、排查结果处置

1. 发现空口令/弱口令账号：改强口令或直接锁定，记录账号名与处置时间进报告。
2. 发现后门账号（UID 0 同名、$ 结尾）：先 `cp /etc/passwd /etc/shadow` 取证，再删除或锁定。
3. 把默认口令清单与自测结果整理成表格，作为「加固有效性」证据写入 Writeup。
