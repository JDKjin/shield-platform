# 应急安全工具集手册

> 应急响应与防御赛常用的开源工具及其用途速查。优先使用系统自带命令完成 90% 工作；工具用于提效，比赛环境慎装新软件（避免被利用）。

## 一、系统自带命令（零依赖）

| 用途 | 命令 |
|------|------|
| 进程排查 | `ps`、`top`、`lsof`、`/proc/<pid>/exe` |
| 网络排查 | `ss`、`netstat`、`lsof -i`、`tcpdump` |
| 文件排查 | `find`、`stat`、`md5sum`、`sha256sum`、`lsattr/chattr` |
| 日志 | `tail`、`grep`、`journalctl`、`last`、`lastb` |
| 账号 | `cat /etc/passwd`、`awk`、`getent` |
| 计划任务 | `crontab -l`、`cat /etc/cron.d/*`、`systemctl list-timers` |
| 完整性 | `rpm -Va`（CentOS）、`debsums`（Ubuntu） |

## 二、检测与排查工具

| 工具 | 用途 | 安装 |
|------|------|------|
| `chkrootkit` | 检查 rootkit 痕迹 | `yum install chkrootkit` / `apt-get install chkrootkit` |
| `rkhunter` | rootkit 扫描（配合基线） | `yum install rkhunter` |
| `clamscan` | 恶意文件扫描（开源杀软） | `apt-get install clamav` |
| `lynis` | 系统安全审计（加固检查） | `git clone github.com/CISOfy/lynis` |
| `nmap` | 端口/服务探测（自查开放面） | `yum install nmap` |
| `fail2ban` | SSH/服务爆破自动封禁 | `yum install fail2ban` |
| `rkhunter` | 完整性/后门基线 | 见上 |

## 三、取证分析工具

| 工具 | 用途 |
|------|------|
| `tcpdump` / `tshark` | 抓包与分析（见「流量抓包与网络取证手册」） |
| `strings` / `readelf` / `strace` | 恶意样本静态/动态分析（见「恶意样本初步分析」） |
| `foremost` / `binwalk` | 文件恢复/隐藏文件提取 |
| `grep -a` | 二进制文件内关键字搜索 |

## 四、Web 与中间件专项

| 工具 | 用途 |
|------|------|
| `curl` | 请求测试/直连业务验证 |
| `sqlmap`（仅授权自查） | 验证注入点是否已修复 |
| `xsss`/`nikto`（自查） | Web 配置扫描 |
| `mysqldump` | 数据库备份 |
| `tar` / `rsync` | 目录备份与恢复 |

## 五、Windows 工具

| 工具 | 用途 |
|------|------|
| `Sysinternals` 套件（Autoruns/Process Explorer/Tcpview） | 启动项/进程/连接排查 |
| `PowerShell` 内置 cmdlet | 事件日志、WMI 排查 |
| `Wireshark` | 抓包分析 |
| `Process Monitor` | 文件/注册表行为监控 |

## 六、使用原则

1. **优先系统自带**：减少安装，避免在比赛靶机引入新风险面。
2. **自查工具必须在授权范围**：`sqlmap`/`nmap`/`hydra` 仅对本队靶机做修复验证。
3. **工具输出入报告**：`rkhunter --check`、`lynis audit system` 的检查结果可直接作为加固有效性证据。
4. **装完即用即管**：不用的服务及时关闭，工具本身不放公网目录。
