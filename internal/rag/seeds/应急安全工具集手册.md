# 应急安全工具集手册

> 应急响应与防御赛常用的开源工具及其用途速查。优先使用系统自带命令完成 90% 工作；工具用于提效，比赛环境慎装新软件（避免被利用）。

## 一、系统自带命令（零依赖）

| 用途 | 命令 |
|------|------|
| 进程排查 | `ps`、`top`、`lsof`、`/proc/<pid>/exe` |
| 网络排查 | `ss`、`netstat`、`lsof -i`、`tcpdump` |
| 文件排查 | `find`、`stat`、`md5sum`、`sha256sum`、`lsattr/chattr` |
| 日志 | `tail`、`grep`、`journalctl`、`last`、`lastb` |
| 账号 | `cat /etc/passwd`、`awk`、`getent` |
| 计划任务 | `crontab -l`、`cat /etc/cron.d/*`、`systemctl list-timers` |
| 完整性 | `rpm -Va`（CentOS）、`debsums`（Ubuntu） |

## 二、检测与排查工具

| 工具 | 用途 | 安装 |
|------|------|------|
| `chkrootkit` | 检查 rootkit 痕迹 | `yum install chkrootkit` / `apt-get install chkrootkit` |
| `rkhunter` | rootkit 扫描（配合基线） | `yum install rkhunter` |
| `clamscan` | 恶意文件扫描（开源杀软） | `apt-get install clamav` |
| `lynis` | 系统安全审计（加固检查） | `git clone github.com/CISOfy/lynis` |
| `nmap` | 端口/服务探测（自查开放面） | `yum install nmap` |
| `fail2ban` | SSH/服务爆破自动封禁 | `yum install fail2ban` |
| `rkhunter` | 完整性/后门基线 | 见上 |

## 三、取证分析工具

| 工具 | 用途 |
|------|------|
| `tcpdump` / `tshark` | 抓包与分析（见「流量抓包与网络取证手册」） |
| `strings` / `readelf` / `strace` | 恶意样本静态/动态分析（见「恶意样本初步分析」） |
| `foremost` / `binwalk` | 文件恢复/隐藏文件提取 |
| `grep -a` | 二进制文件内关键字搜索 |

## 四、Web 与中间件专项

| 工具 | 用途 |
|------|------|
| `curl` | 请求测试/直连业务验证 |
| `sqlmap`（仅授权自查） | 验证注入点是否已修复 |
| `xsss`/`nikto`（自查） | Web 配置扫描 |
| `mysqldump` | 数据库备份 |
| `tar` / `rsync` | 目录备份与恢复 |

## 五、Windows 工具

| 工具 | 用途 |
|------|------|
| `Sysinternals` 套件（Autoruns/Process Explorer/Tcpview） | 启动项/进程/连接排查 |
| `PowerShell` 内置 cmdlet | 事件日志、WMI 排查 |
| `Wireshark` | 抓包分析 |
| `Process Monitor` | 文件/注册表行为监控 |

## 六、使用原则

1. **优先系统自带**：减少安装，避免在比赛靶机引入新风险面。
2. **自查工具必须在授权范围**：`sqlmap`/`nmap`/`hydra` 仅对本队靶机做修复验证。
3. **工具输出入报告**：`rkhunter --check`、`lynis audit system` 的检查结果可直接作为加固有效性证据。
4. **装完即用即管**：不用的服务及时关闭，工具本身不放公网目录。

## 补强篇：完整命令速查（GUI / 无头服务器双路径）

> 本篇面向新手，所有命令均可直接复制运行。每节按「图形化（GUI）路径」与「无头服务器（CLI）路径」分别给出，覆盖 Linux（CentOS 7 / Ubuntu 20.04）与 Windows Server 2016 两种系统。

### 1. Linux 应急工具完整运行命令

#### 1.1 chkrootkit（rootkit 痕迹扫描）

GUI 路径（带桌面环境的 Ubuntu / CentOS）：
```bash
# 安装
sudo yum install -y epel-release && sudo yum install -y chkrootkit   # CentOS 7
sudo apt-get update && sudo apt-get install -y chkrootkit            # Ubuntu 20.04
# 在 GNOME Terminal 中运行并把结果输出到图形化文本编辑器
sudo chkrootkit 2>&1 | tee ~/chkrootkit-$(date +%F).log
gedit ~/chkrootkit-$(date +%F).log
```

无头服务器（CLI）路径：
```bash
sudo chkrootkit 2>&1 | tee /var/log/chkrootkit-$(date +%F).log
# 仅打印可疑项
sudo chkrootkit 2>&1 | grep -iE 'INFECTED|suspicious|not found'
```

#### 1.2 rkhunter（rootkit 扫描 + 完整性基线）

GUI 路径：
```bash
sudo yum install -y rkhunter          # CentOS 7
sudo apt-get install -y rkhunter      # Ubuntu 20.04
# 首次运行前更新特征库
sudo rkhunter --update
sudo rkhunter --propupd
# 扫描并查看报告
sudo rkhunter --check --sk
gedit /var/log/rkhunter.log
```

无头服务器路径：
```bash
sudo rkhunter --update && sudo rkhunter --propupd
sudo rkhunter --check --sk --report-warnings-only 2>&1 | tee /var/log/rkhunter-$(date +%F).log
```

#### 1.3 clamscan（ClamAV 开源杀软扫描）

GUI 路径（Ubuntu 可装 clamtk 图形前端）：
```bash
sudo apt-get install -y clamav clamtk
sudo freshclam
clamtk   # 图形界面选择目录扫描
```

无头服务器路径：
```bash
sudo yum install -y epel-release && sudo yum install -y clamav clamav-update   # CentOS
sudo apt-get install -y clamav clamav-daemon                                    # Ubuntu
sudo freshclam
# 全盘扫描，仅打印感染文件，结果写日志
sudo clamscan -r --infected --remove=yes / 2>&1 | tee /var/log/clamscan-$(date +%F).log
# 指定目录扫描（不删，仅记录）
sudo clamscan -r -i /var/www /tmp /home 2>&1 | tee /tmp/clamscan-www.log
```

#### 1.4 lynis（系统安全审计）

GUI 路径：
```bash
sudo yum install -y lynis          # CentOS（需 EPEL）
sudo apt-get install -y lynis      # Ubuntu
sudo lynis audit system
gedit /var/log/lynis.log
gedit /var/log/lynis-report.dat
```

无头服务器路径：
```bash
sudo lynis audit system --quiet 2>&1 | tee /var/log/lynis-$(date +%F).log
# 仅输出警告项
sudo lynis audit system --quiet | grep -E '^Warning|^Suggestion'
```

#### 1.5 AIDE（高级入侵检测环境，文件完整性）

GUI 路径：
```bash
sudo yum install -y aide           # CentOS 7
sudo apt-get install -y aide       # Ubuntu 20.04
sudo aide --init
sudo cp /var/lib/aide/aide.db.new.gz /var/lib/aide/aide.db.gz
sudo aide --check | tee ~/aide-check-$(date +%F).log
```

无头服务器路径：
```bash
sudo aide --init && sudo cp /var/lib/aide/aide.db.new.gz /var/lib/aide/aide.db.gz
sudo aide --check 2>&1 | tee /var/log/aide-check-$(date +%F).log
```

#### 1.6 foremost（文件恢复 / 隐藏文件提取）

GUI 路径：
```bash
sudo yum install -y foremost       # CentOS（EPEL）
sudo apt-get install -y foremost   # Ubuntu
# 从镜像中恢复图片到指定目录
sudo foremost -t all -i /dev/sdb1 -o ~/foremost-out
nautilus ~/foremost-out
```

无头服务器路径：
```bash
sudo foremost -t jpg,png,pdf,zip -i forensic.dd -o /var/foremost-out
# -t 指定文件类型，-i 输入，-o 输出
sudo foremost -t all -i /dev/sdc -o /var/foremost-usb 2>&1 | tee /tmp/foremost.log
```

#### 1.7 binwalk（固件 / 隐藏内容提取）

GUI 路径：
```bash
sudo apt-get install -y binwalk    # Ubuntu
sudo yum install -y binwalk        # CentOS（EPEL）
binwalk firmware.bin | tee ~/binwalk-scan.txt
gedit ~/binwalk-scan.txt
# 递归提取
binwalk -e firmware.bin
```

无头服务器路径：
```bash
binwalk -e --matryoshka --depth=2 firmware.bin 2>&1 | tee /var/log/binwalk-$(date +%F).log
binwalk -A suspicious.bin   # 显示熵与可执行签名
```

#### 1.8 strings（二进制内可见字符串提取）

GUI 路径：
```bash
strings -n 6 suspicious.elf | tee ~/strings-out.txt
gedit ~/strings-out.txt
```

无头服务器路径：
```bash
# 最小长度 6，过滤可疑关键字
strings -n 6 /tmp/suspicious.elf | grep -iE 'http|/tmp/|/bin/sh|curl|wget|bash -i' | tee /var/log/strings-hit.log
# 同时对 ELF 做 readelf 与 file 识别
file /tmp/suspicious.elf
readelf -h /tmp/suspicious.elf
```

#### 1.9 strace（动态行为追踪）

GUI 路径：
```bash
sudo strace -f -tt -o ~/strace-out.log /path/to/suspicious_binary
gedit ~/strace-out.log
```

无头服务器路径：
```bash
# -f 跟踪子进程，-tt 微秒时间戳，-e 只看文件与网络相关调用
sudo strace -f -tt -e trace=open,openat,connect,execve -o /var/log/strace-$(date +%F).log /path/to/suspicious_binary
# 仅追踪已运行进程（PID 1234）
sudo strace -p 1234 -f -tt -o /var/log/strace-pid1234.log
```

### 2. Windows 应急工具 PowerShell 命令（Windows Server 2016）

> Windows Server 2016 默认以 Server Core / 无桌面方式部署较多，PowerShell 是双路径通用入口：GUI 服务器在「服务器管理器 → 工具」打开 PowerShell ISE；无头服务器通过 WinRM 或 sconfig 进入 PowerShell。

#### 2.1 Get-WinEvent（事件日志查询）

GUI 路径（事件查看器 + PowerShell ISE）：
```powershell
# 在 PowerShell ISE 中执行
Get-WinEvent -LogName Security -MaxEvents 50 | Format-Table TimeCreated, Id, Message -AutoSize
```

无头服务器路径（WinRM / sconfig）：
```powershell
# 列出最近 1 小时的安全日志中 4625（登录失败）事件
$StartTime = (Get-Date).AddHours(-1)
Get-WinEvent -FilterHashtable @{LogName='Security'; Id=4625; StartTime=$StartTime} |
  Select-Object TimeCreated, Id, @{N='TargetUser';E={$_.Properties[5].Value}}, @{N='SourceIP';E={$_.Properties[19].Value}} |
  Format-Table -AutoSize | Out-File C:\Logs\4625.txt
```

#### 2.2 Get-Process（进程排查）

GUI 路径：
```powershell
# 任务管理器 + PowerShell
Get-Process | Sort-Object CPU -Descending | Select-Object -First 20 Name, Id, CPU, Path | Format-Table -AutoSize
```

无头服务器路径：
```powershell
Get-Process | Where-Object {$_.Path -like '*\Temp\*' -or $_.Path -like '*\Users\Public\*'} |
  Select-Object Name, Id, Path | Format-Table -AutoSize | Out-File C:\Logs\suspicious-proc.txt
# 查找无数字签名的进程
Get-Process | ForEach-Object { Get-AuthenticodeSignature $_.Path } | Where-Object {$_.Status -ne 'Valid'} | Format-Table Path, Status
```

#### 2.3 Get-NetTCPConnection（网络连接）

GUI 路径：
```powershell
Get-NetTCPConnection -State Established |
  Select-Object LocalAddress, LocalPort, RemoteAddress, RemotePort, OwningProcess |
  Format-Table -AutoSize
```

无头服务器路径：
```powershell
Get-NetTCPConnection -State Established |
  ForEach-Object {
    $p = Get-Process -Id $_.OwningProcess -ErrorAction SilentlyContinue
    [PSCustomObject]@{
      Local  = "$($_.LocalAddress):$($_.LocalPort)"
      Remote = "$($_.RemoteAddress):$($_.RemotePort)"
      PID    = $_.OwningProcess
      Proc   = $p.Name
      Path   = $p.Path
    }
  } | Format-Table -AutoSize | Out-File C:\Logs\netconn.txt
```

#### 2.4 Get-ScheduledTask（计划任务）

GUI 路径：
```powershell
Get-ScheduledTask | Where-Object {$_.State -ne 'Disabled'} |
  Select-Object TaskName, TaskPath, State | Format-Table -AutoSize
```

无头服务器路径：
```powershell
Get-ScheduledTask | Where-Object {$_.State -ne 'Disabled' -and $_.TaskPath -notlike '\Microsoft\*'} |
  ForEach-Object {
    [PSCustomObject]@{
      Task    = $_.TaskName
      Path    = $_.TaskPath
      Actions = ($_.Actions.Execute -join ';')
    }
  } | Format-Table -AutoSize | Out-File C:\Logs\sched.txt
```

#### 2.5 wevtutil（命令行事件日志导出）

GUI 路径：
```powershell
# 导出 Security 日志为 evtx
wevtutil epl Security C:\Logs\Security-$(Get-Date -Format yyyyMMdd).evtx
```

无头服务器路径：
```powershell
# 导出所有安全相关日志并打包
wevtutil epl Security C:\Logs\Sec.evtx
wevtutil epl System    C:\Logs\Sys.evtx
wevtutil epl Application C:\Logs\App.evtx
# 查询指定事件
wevtutil qe Security "/q:*[System[(EventID=4624)]]" /c:50 /f:text /rd:true
```

```powershell
C:\Tools\Sysinternals\autorunsc64.exe -accepteula -a * -c -h -s -v -vt > C:\Logs\autoruns.csv
```

### 4. Wireshark 与 tshark 无头分析命令对照

#### 4.1 安装

GUI 路径：
```bash
# Ubuntu 桌面
sudo apt-get install -y wireshark tshark
# CentOS 桌面（需 EPEL + Nux）
sudo yum install -y wireshark wireshark-gnome
```

无头服务器路径：
```bash
sudo apt-get install -y tshark       # Ubuntu Server
sudo yum install -y wireshark        # CentOS 7（仅 tshark CLI）
```

#### 4.2 常见过滤表达式（GUI 与 tshark 通用）

| 场景 | 过滤表达式 |
|------|------------|
| 仅看 HTTP POST 请求 | `http.request.method == POST` |
| DNS 查询 | `dns.qry.name contains "evil"` |
| 指定 IP 流量 | `ip.addr == 192.168.1.10` |
| Modbus 工控流量 | `modbus` 或 `modbus.func_code == 16` |
| TCP SYN 扫描 | `tcp.flags.syn == 1 && tcp.flags.ack == 0` |
| TLS SNI 含特定域名 | `tls.handshake.extensions_server_name contains "c2"` |

GUI 路径（Wireshark 图形界面）：
1. 捕获 → 选项 选择网卡
2. 显示过滤器栏粘贴 `http.request.method == POST` 回车
3. 文件 → 导出特定分组保存

无头服务器路径（tshark）：
```bash
# 实时抓取并按过滤器打印
sudo tshark -i eth0 -Y 'http.request.method == POST' -T fields -e ip.src -e http.host -e http.request.uri
# 抓 60 秒写入 pcap，再离线分析
sudo tshark -i eth0 -a duration:60 -w /tmp/http.pcap
tshark -r /tmp/http.pcap -Y 'modbus' -T fields -e ip.src -e ip.dst -e modbus.func_code
tshark -r /tmp/http.pcap -Y 'http.request.method == POST' -T fields -e frame.time -e ip.src -e http.request.uri -e http.file_data
```

Windows Server 2016 路径（安装 Wireshark 后使用 tshark.exe）：
```powershell
& 'C:\Program Files\Wireshark\tshark.exe' -i 1 -Y 'http.request.method == POST' -T fields -e ip.src -e http.host
& 'C:\Program Files\Wireshark\tshark.exe' -r C:\cap\http.pcap -Y 'modbus' -w C:\cap\modbus.pcap
```

### 5. tcpdump 抓包完整命令

GUI 路径（带桌面环境，可配合 Wireshark 图形查看）：
```bash
sudo tcpdump -i eth0 -nn -w ~/cap-$(date +%F).pcap
# Ctrl+C 停止后用 wireshark 打开
wireshark ~/cap-$(date +%F).pcap
```

无头服务器路径：
```bash
# 列出可用网卡
sudo tcpdump -D
# 抓 eth0 所有流量，不解析域名/端口，写文件 + 实时打印
sudo tcpdump -i eth0 -nn -l -w /var/log/tcpdump-$(date +%F).pcap 'tcp or udp'
# 只抓 80 与 443 端口，最多 1000 个包
sudo tcpdump -i eth0 -nn -c 1000 'port 80 or port 443' -w /tmp/web.pcap
# 抓 ICMP 与 SSH
sudo tcpdump -i eth0 -nn 'icmp or port 22' -w /tmp/icmp-ssh.pcap
# 抓指定主机流量
sudo tcpdump -i eth0 -nn 'host 192.168.1.100' -w /tmp/host.pcap
# 抓 SYN 包（扫描识别）
sudo tcpdump -i eth0 -nn 'tcp[tcpflags] & tcp-syn != 0 and tcp[tcpflags] & tcp-ack == 0'
```

参数速查：
- `-i eth0` 指定网卡
- `-nn` 不解析 IP 与端口（更快）
- `-w file.pcap` 写入 pcap
- `-c N` 抓 N 个包后退出
- `-l` 行缓冲（便于实时管道处理）
- `'port 22'` / `'host x.x.x.x'` BPF 过滤

### 6. nmap 自查开放面命令

GUI 路径（Zenmap 图形前端）：
```bash
sudo yum install -y nmap          # CentOS
sudo apt-get install -y nmap      # Ubuntu
# 启动 Zenmap
zenmap
# Profile 选 "Intense scan, all TCP ports"，目标填 127.0.0.1
```

无头服务器路径：
```bash
# 全端口 SYN 扫描 + 服务版本识别（仅本机自查）
sudo nmap -sS -sV -p- 127.0.0.1 -oN /var/log/nmap-self.txt
# 指定常见高危端口
sudo nmap -sS -sV -p 21,22,23,3389,5900,6379,27017 127.0.0.1
# UDP 顶层 100 端口（需 root）
sudo nmap -sU --top-ports 100 127.0.0.1 -oN /var/log/nmap-udp.txt
# 扫描本机对外开放面（注意：仅对自有靶机）
sudo nmap -sS -sV -p- --open 127.0.0.1
```

Windows Server 2016 路径（nmap 官方安装包含 Zenmap 与 nmap.exe）：
```powershell
& 'C:\Program Files (x86)\Nmap\nmap.exe' -sS -sV -p- 127.0.0.1 -oN C:\Logs\nmap-self.txt
```

### 7. fail2ban 完整配置示例

> 适用于 CentOS 7 / Ubuntu 20.04。SSH 爆破是 AWD/CTF 中最常见的攻击面之一。

GUI 路径（带桌面环境，编辑器 + 终端）：
```bash
sudo yum install -y epel-release fail2ban fail2ban-firewalld   # CentOS 7
sudo apt-get install -y fail2ban                                # Ubuntu 20.04
sudo systemctl enable --now fail2ban
sudo gedit /etc/fail2ban/jail.local
```

无头服务器路径：
```bash
sudo yum install -y epel-release fail2ban fail2ban-firewalld   # CentOS 7
sudo apt-get install -y fail2ban                                # Ubuntu 20.04
sudo systemctl enable --now fail2ban
sudo tee /etc/fail2ban/jail.local > /dev/null <<'EOF'
[DEFAULT]
# 封禁 1 小时
bantime  = 3600
# 时间窗口 10 分钟
findtime = 600
# 5 次失败即封
maxretry = 5
# CentOS 用 firewalld，Ubuntu 用 iptables
banaction = firewallcmd-rich-rules
# banaction = iptables-multiport

[sshd]
enabled  = true
port     = ssh
logpath  = %(sshd_log)s
backend  = systemd
maxretry = 3
bantime  = 86400
EOF

sudo systemctl restart fail2ban
# 验证状态
sudo fail2ban-client status
sudo fail2ban-client status sshd
# 查看当前被封 IP
sudo fail2ban-client banned
# 手动解封
sudo fail2ban-client set sshd unbanip 1.2.3.4
```

#### 8.1 RPM 包基线（CentOS 7）


无头服务器路径：
```bash
# 首次建立基线（系统干净时执行）
```

#### 8.2 关键文件 sha256sum 基线（CentOS / Ubuntu 通用）

```bash

```

无头服务器路径：
```bash
# 建立基线
sudo find /etc -type f \( -name '*.conf' -o -name '*.cfg' \) -exec sha256sum {} \; > /root/baseline/etc-sha256-$(date +%F).txt

sudo find /etc -type f \( -name '*.conf' -o -name '*.cfg' \) -exec sha256sum {} \; > /root/baseline/etc-sha256-current.txt
```


#### 8.5 Windows Server 2016 完整性基线

GUI 路径：
```powershell
# 系统关键文件哈希基线
Get-FileHash C:\Windows\System32\cmd.exe, C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe -Algorithm SHA256 |
  Export-Csv C:\Baseline\win-baseline.csv -NoTypeInformation
```

无头服务器路径：
```powershell
# 批量生成系统目录哈希基线
Get-ChildItem C:\Windows\System32\*.exe | ForEach-Object {
  Get-FileHash $_.FullName -Algorithm SHA256
} | Export-Csv C:\Baseline\sys32-baseline.csv -NoTypeInformation

# 对比（事后执行）
$base = Import-Csv C:\Baseline\sys32-baseline.csv
foreach ($f in $base) {
  $h = (Get-FileHash $f.Path -Algorithm SHA256 -ErrorAction SilentlyContinue).Hash
  if ($h -ne $f.Hash) { "$($f.Path) CHANGED" | Out-File C:\Logs\changed.txt -Append }
}
```
