# 内网横向移动攻击检测与防御手册

> 能源防御赛靶机群同网段，横向移动是攻击方从一台打到整片的主要手段（SSH 口令复用、SMB 445、RDP、计划任务、PsExec）。防守目标：封横向通道、查被当跳板、断信任关系。

## 一、横向移动常见手法与检测特征

| 手法 | 特征 | 检测点 |
|------|------|--------|
| SSH 口令复用 | 兄弟靶机来源的 SSH 登录 | `grep Accepted /var/log/secure` 非本机来源 |
| SMB/WMI/PsExec | 445/135 端口入站、新服务 | `ss -tlnp` 看 445/135、7045 事件（Win） |
| 计划任务横向 | 兄弟靶机写 crontab | `ls -la /var/spool/cron/` mtime 突变 |
| RDP | 3389 远程登录 | 4624 登录事件来源 IP |
| Pass-the-Hash | 凭据哈希复用 | 事件日志异常登录 + 兄弟机同样中招 |

## 二、Linux 检测

```bash
# 1. 兄弟靶机来的登录
grep -E 'Accepted' /var/log/secure | grep -vE '<自己IP>|<管理IP>'

# 2. 异常连接：横向扫描/回连（对照业务白名单）
ss -tnp | grep -E 'ESTAB' | awk '{print $5}' | grep -vE '^127\.|^192\.168\.(0|1)\.(管理段)'
ss -tnp | grep -E ':445 |:135 |:22 ' 

# 3. 被新增的计划任务 / 启动项（横向常在此落盘）
ls -la /var/spool/cron/ /etc/cron.d/ /etc/rc.d/rc.local
# 4. 新增账号 / SSH 公钥（横向后种后门）
grep -nE 'wget|curl|/dev/tcp' /var/spool/cron/* /etc/cron.d/* 2>/dev/null
find /root /home -name authorized_keys -mmin -120
```

## 三、Windows 检测

```powershell
# 兄弟靶机来源的 4624 成功登录
Get-WinEvent -FilterHashtable @{LogName='Security';Id=4624} |
  Where-Object { $_.Properties[18].Value -notmatch '^(127\.|管理段)' } |
  Select TimeCreated, @{n='IP';e={$_.Properties[18].Value}}

# 445 连接（SMB 横向）与 RDP
netstat -ano | findstr ":445" ; netstat -ano | findstr ":3389"
# 新增服务（PsExec 特征 7045）
Get-WinEvent -FilterHashtable @{LogName='System';Id=7045} | Select TimeCreated, Message
```

## 四、防御与切断

```bash
# 1. 封横向高危端口（保留业务必要端口）
iptables -I INPUT -p tcp --dport 445 -j DROP
iptables -I INPUT -p tcp --dport 139 -j DROP
iptables -I INPUT -p tcp --dport 135 -j DROP
# 2. 限制 SSH 来源（只放行自己/管理机）
iptables -I INPUT -p tcp --dport 22 -s <自己IP> -j ACCEPT
iptables -I INPUT -p tcp --dport 22 -j DROP
# 3. 禁止出站回连（封兄弟靶机作为 C2）
iptables -I OUTPUT -d <兄弟靶机IP> -j DROP
```

```powershell
# Windows 禁用 SMB/NetBIOS 入站
Set-NetFirewallRule -DisplayGroup 'File and Printer Sharing' -Enabled False
# 关闭 RDP 或限制来源
Set-ItemProperty -Path 'HKLM:\System\CurrentControlSet\Control\Terminal Server' -Name fDenyTSConnections -Value 1
# 断信任：清理兄弟机植入的公钥/凭据
```

## 五、凭据清理与信任隔离

1. **改全部口令**：兄弟靶机互相复用的口令一旦泄露就是全片失守，所有靶机统一换强口令。
2. **清 SSH 信任**：删 `authorized_keys` 中非本人公钥、`/root/.ssh/known_hosts` 异常记录。
3. **关可写共享**：`/tmp`、Web 上传目录、共享盘保持最小写权限，禁执行。
4. **确认未被当跳板**：`grep 兄弟IP /var/log/secure` 若发现反向连接记录，说明本机已被横向利用，按「应急响应 SOP」处置。

## 六、报告要点

按「入口机 → 跳板 → 目标机」链路写横向移动溯源，附兄弟机来源的登录/连接日志截图，证明已封通道并清理信任关系。
