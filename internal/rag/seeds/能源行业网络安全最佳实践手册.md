# 能源行业网络安全最佳实践手册

> 面向能源综合防御赛（发电 / 电网 / 油气）的行业级防护基线。结合官方考核模块（应急监测、溯源分析、安全加固）与工控场景特点，给出防守方应建立的体系化做法。

## 一、能源行业资产面（攻击方视角）

| 资产类型 | 典型组件 | 高危点 |
|---------|---------|--------|
| 生产控制网 | SCADA/HMI、PLC、RTU | 协议未授权、后台弱口令、Web 管理暴露 |
| 调度与远动 | IEC 104、DNP3 网关 | 遥测/遥控报文伪造 |
| 业务网 | 电力营销系统、工控数据库 | Web 漏洞、数据库弱口令 |
| 监控系统 | OPC UA 服务器、历史数据库 | 未授权读写 |
| 办公/运维 | 堡垒机、VPN、工单系统 | 弱口令、接口暴露 |

## 二、工控协议安全基线

1. **最小开放**：工控端口（Modbus 502、IEC104 2404、DNP3 20000、OPC UA 4840、S7 102）只对必要的主站/工作站开放，`ss -tlnp` 出现陌生监听即排查。
2. **功能码收敛**：写操作功能码（Modbus 05/06/15/16、DNP3 控制点）在网关上做白名单与校验。
3. **隔离与单向**：生产网与办公网逻辑隔离，数据采集单向传输。
4. **工控 WAF/白名单**：对工控 Web 后台部署软 WAF，规则库启用「协议攻击」「工控安全」类规则。

## 三、能源监控系统（SCADA/HMI）安全

1. **后台口令**：SCADA/HMI Web 后台默认口令（admin/admin、admin/123456）全部改强口令。
2. **后台来源限制**：管理后台绑定内网/来源 IP 白名单。
3. **会话与审计**：登录会话超时、操作日志记录（谁在何时读写遥测点）。
4. **数据完整性**：历史数据/遥测表只读，写库账号最小权限。

## 四、针对三种攻击模式的防守

| 模式 | 重点 | 防守动作 |
|------|------|---------|
| 红队渗透 | 针对工控业务链路的定向攻击 | 实时告警 + 快速封源 + 后门清理 |
| 自动化脚本 | 批量弱口令/已知 CVE 载荷 | 改默认口令、补已知漏洞、WAF 覆盖 |
| 历史流量回放 | 特定工控报文字段攻击 | 记录业务报文基线，对比异常写操作 |

## 五、能源场景应急要点

1. **工控业务不可中断**：加固与 WAF 调参以不打断正常采集/控制为底线，先 alert 后 block。
2. **操作类攻击优先取证**：Modbus 写线圈/寄存器、IEC104 遥控报文，`tcpdump` 抓包 + 后台操作日志双通道取证。
3. **Flag 常在工控数据中**：flag 可能藏在历史数据库、SCADA 报表、工控后台数据区，按「Flag 与敏感文件防护手册」藏好。
4. **写报告对齐官方模块**：应急监测（做了什么监测/拦截）→ 溯源分析（攻击源/后门/时间线）→ 安全加固（配置前后对比），与官方三类考核模块一一对应。

## 六、比赛节奏建议

1. 开局：按「能源网络应急监测」建全资产清单与基线（进程/端口/文件 hash/业务报文）。
2. 赛中：每轮结束对比基线增量，抓「攻击失败轮次」白拿分窗口。
3. 收尾：按「能源网络溯源分析 / 安全加固」写全证据链，工控专项动作（封端口、收敛功能码、改后台口令）全部截图进报告。
