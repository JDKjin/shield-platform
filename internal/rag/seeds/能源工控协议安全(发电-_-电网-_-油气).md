# 能源工控协议安全（发电 / 电网 / 油气）

## 常见工控协议与端口
- Modbus TCP：502，功能码读 01/02/03/04，写 05/06/15/16；无原生认证
- IEC 60870-5-104（IEC104）：2404，用于电网远动，无强认证
- DNP3：20000，SCADA 常用，支持写操作
- OPC UA：4840，现代工控互通，支持账号认证（常被弱口令）
- S7（西门子）：102，PLC 编程与数据访问
- MQTT：1883/8883，物联网遥测，常匿名

## 协议层风险：Modbus 写线圈 / 未授权读写 / 重放
- 未授权读写：直接发送写功能码修改线圈/寄存器（启停设备、篡改遥测）
- 重放攻击：重放历史控制指令
- 中间人：明文协议可被窃听/篡改
- 默认/弱口令：OPC UA、HMI、网关管理后台

## 加固与防护建议
- 网络隔离：工控网与生产网/办公网分段，VLAN + ACL
- 协议白名单：防火墙仅放行必要的功能码与地址区间
- 关闭不必要的写权限；对关键控制指令启用双人复核/硬件联锁
- 修改默认口令、启用 OPC UA 认证与加密
- 部署工控 IDS（如利用 Suricata 的 modbus/iec104 规则）检测异常写操作
- 监控遥测突变：同一遥测点短时间内大幅跳变、批量写操作

## 本题防御重点
能源综合防御赛的「energy_ics」规则检测的目标是：HTTP 管理接口中携带的危险工控操作（如写入线圈、下发控制指令、调用停止/启动设备、协议端口探测），以及异常协议字段。命中后应拦截并记录，便于溯源报告说明攻击意图。
