# 常见端口与默认服务速查表

> 应急与加固时的端口速查：`ss -tlnp` 出现非常规监听端口 = 后门信号；未知服务占用端口 = 需要核查。配合「Linux 持久化后门排查手册」使用。

## 一、常规业务端口（对照基线）

| 端口 | 服务 | 说明 |
|------|------|------|
| 21 | FTP | 弱口令/匿名登录排查点 |
| 22 | SSH | 爆破与后门高发口 |
| 23 | Telnet | 明文，比赛建议关闭 |
| 25/465/587 | SMTP | 邮件服务 |
| 80/443 | HTTP/HTTPS | Web |
| 3306 | MySQL | 勿对公网开放 |
| 5432 | PostgreSQL | 勿对公网开放 |
| 6379 | Redis | 未授权访问排查重点 |
| 8080 | Tomcat / 面板 | 管理后台核查 |
| 8443 | HTTPS 管理 | Tomcat/面板 |
| 9090 | 各种管理服务 | 常见面板端口 |
| 3389 | RDP | Windows 远程桌面，横向利用点 |
| 445/139/135 | SMB/NetBIOS | 横向移动高危口 |

## 二、后门/攻击特征端口（非常规出现要警惕）

| 端口 | 常见用途 |
|------|---------|
| 4444 / 5555 / 6666 | 反弹 shell、Metasploit 默认 |
| 8888 | WebShell 反弹、代理 |
| 31337 / 1337 | 常见后门端口 |
| 1090 / 1080 | 代理后门 |
| 9000-9005 | php-fpm / 调试代理 |
| 53 | DNS 隧道（出站异常查询） |
| 8081-8090 | 端口转发/代理后门高发段 |

> 判断原则：业务不需要的监听端口一律核查来源；`ss -tlnp` 中进程名异常（随机名、`[kworker]` 伪装、/tmp 路径）即按后门处理。

## 三、能源/工控协议端口（能源防御赛专项）

| 端口 | 协议 | 说明 |
|------|------|------|
| 502 | Modbus TCP | 工控协议，未授权可读写寄存器 |
| 102 | S7 | Siemens S7 工控协议 |
| 2404 | IEC 60870-5-104 | 电力远动协议 |
| 20000 | DNP3 | 电力数据采集协议 |
| 4840 | OPC UA | 工业自动化通信 |
| 623 | IPMI | 服务器带外管理 |

工控端口出现陌生连接、未授权读写 = 能源专项攻击信号（详见「能源工控协议安全」手册）。

## 四、应急处置示例

```bash
# 列出全部监听端口与进程
ss -tlnp
# 定位占用端口的进程
lsof -i :8081
# 非业务端口直接封
iptables -I INPUT -p tcp --dport 8081 -j DROP
# 核对进程来源后处置
ls -l /proc/<pid>/exe
```

## 五、Windows 端口速查

```powershell
netstat -ano | findstr "LISTENING"
tasklist /fi "pid eq <PID>"
```

新增监听（对照基线）、非常规端口被外部连接，立即按「Windows 事件日志」手册排查对应进程来源。
